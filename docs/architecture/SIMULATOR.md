# Growth Simulator: Merchant Growth Autopilot

This document specifies the mathematical formulations, inputs, outputs, confidence interval calculations, and seed-handling mechanics of the Growth Simulator.

## 1. Mathematical Formulation

The Growth Simulator predicts campaign outcomes deterministically in Node.js, ensuring that the LLM cannot hallucinate or fabricate results.

### 1.1 Expected Revenue Uplift
The expected revenue uplift represents the incremental gross revenue generated by the campaign:
\[E[\Delta R] = (S \times \Delta p) \times AOV\]

Where:
- \(S\): Size of the target customer segment.
- \(\Delta p\): Expected conversion rate uplift (expressed as a decimal fraction, e.g., 0.072 for 7.2%).
- \(AOV\): Baseline Average Order Value of the target segment (in Paise).

---

### 1.2 Expected Campaign Cost
The expected budget spent due to discount redemptions:
\[E[C] = [S \times (p_0 + \Delta p)] \times R_{red} \times D\]

Where:
- \(p_0\): Baseline conversion rate of the segment (expressed as a decimal fraction).
- \(R_{red}\): Expected redemption rate of the discount coupon (defaults to `0.80` or 80%).
- \(D\): Average unit discount value (in Paise). Calculated as:
  \[D = \min(\text{maxDiscountAmount}, \text{AOV} \times \text{discountPercentage})\]

---

### 1.3 Net Profit Impact
The projected net contribution to margins:
\[E[\Delta \Pi] = (E[\Delta R] \times M) - E[C]\]

Where:
- \(M\): Gross margin percentage of the merchant (defaults to `0.40` or 40%).

---

### 1.4 ROI (Return on Investment)
\[ROI = \frac{E[\Delta \Pi]}{E[C]} = \frac{(E[\Delta R] \times M) - E[C]}{E[C]}\]
If \(E[C] = 0\), ROI is calculated as \(\infty\).

---

## 2. Confidence Intervals (95% Confidence)
To prevent the agent from selecting risky strategies based on small sample cohorts, we calculate a 95% Confidence Interval for the uplift change \(\Delta p\).

The standard error of the conversion proportion is:
\[SE = \sqrt{\frac{p_0 \cdot (1 - p_0)}{N_s}}\]

Where:
- \(N_s\): Number of historical payment attempts (sample size) in the segment.

The 95% Confidence Interval limits for conversion rate uplift are:
\[\text{Lower Bound} = \max\left(0, \Delta p - 1.96 \cdot SE \cdot \left(1 + \frac{100}{N_s}\right)\right)\]
\[\text{Upper Bound} = \Delta p + 1.96 \cdot SE\]

The scaling factor \(\left(1 + \frac{100}{N_s}\right)\) mathematically penalizes small segments (where \(N_s < 500\)), increasing the uncertainty gap and decreasing the lower bound. This forces the cognitive agent to favor larger, more predictable segments when constraints are strict.

## 3. Zod Schema Signature

```typescript
import { z } from 'zod';

export const SimulatorInputSchema = z.object({
  segmentSize: z.number().min(1),
  sampleSize: z.number().min(1), // Historical transaction count
  baselineConversion: z.number().min(0).max(1), // as ratio
  averageOrderValue: z.number().min(1), // in Paise
  expectedUplift: z.number().min(0).max(1), // as ratio
  discountPercentage: z.number().min(0).max(100).optional(),
  maxDiscountAmount: z.number().min(0).optional(),
  minOrderAmount: z.number().min(0).optional(),
  budgetCap: z.number().min(0)
});

export const SimulatorOutputSchema = z.object({
  expectedUpliftPercent: z.number(),
  expectedRevenueUplift: z.number(), // in Paise
  expectedCampaignCost: z.number(), // in Paise
  netProfitImpact: z.number(), // in Paise
  roi: z.number(),
  confidenceInterval: z.object({
    lower: z.number(),
    upper: z.number()
  }),
  riskLevel: z.enum(['low', 'medium', 'high'])
});
```

## 4. Scenario Seeds Handling
During mock executions and evaluations, we ensure deterministic outputs by loading pre-defined scenario parameters:
- **`upi_failure_spike`**: Overwrites baseline conversion to 40% for SBI/HDFC, locks target uplift projection at 12% on Card Fallback.
- **`aov_decline`**: Forces segment size to 10,000, AOV to ₹800, setting uplift ceiling to 8%.
- **`cart_recovery`**: Sets baseline conversion to 0%, expected recovery rate to 15%.
This ensures that evaluation scripts running the simulator produce identical figures for testing.
